App icon gallery

The shared icons of all apps, existing and planned, in four styles. Each style folder in src/img/app-icons/ holds an SVG, PNG renditions (16 to 512 px), a multi-size ICO, an apple touch icon, and maskable install icons per app. Shown at 128, 48, 32, and 20 px, then as a touch icon and a maskable icon cropped the way devices crop them. Apps use blue flat for favicons and logos and blue dimensional for install icons. Regenerate with python scripts/generate-app-icons.py.
