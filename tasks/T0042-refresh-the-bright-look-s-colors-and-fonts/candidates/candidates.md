# T0042 bright look candidates
Each candidate re-hues the current primitives at the same WCAG luminance per step.
Every candidate passes the full token test: AA pairs, status contrast, and accent variants.

## Current (`b0-current`)
Today's values, for reference.
- Fonts: system-ui headings, system-ui body.
- Light: primary `#1a56db`, background `#f5f7fa`, text `#0f172a`.
- Dark: primary `#60a5fa`, background `#0f172a`, text `#f5f7fa`.
- Boards: [light](b0-current-light.png), [dark](b0-current-dark.png).
