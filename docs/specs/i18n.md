# Internationalization
The shared [i18n.js](../../src/js/i18n.js) module exports `setCatalog`, `t`, and `applyTranslations`.
Each locale supplies one JSON object with flat dotted keys and string values:

```json
{
    "common.save": "Save",
    "common.name": "Name",
    "common.greeting": "Hello, {user-name}!"
}
```

Component keys follow `{{component-key}}.{{string-name}}`; application keys may use their own namespaces.
The shell loads the catalog and selects the locale:

```js
import { setCatalog, t, applyTranslations } from './js/i18n.js';

// Supply the parsed JSON catalog loaded by your application.
setCatalog(catalog);
document.documentElement.lang = 'en';
applyTranslations();
const greeting = t('common.greeting', { 'user-name': 'Ada' });
```

`setCatalog(catalog)` copies and replaces the catalog without applying translations automatically.
Invalid catalogs throw `TypeError` and leave the active catalog unchanged.
Missing keys return the key; empty translations remain empty.
`t(key, params = {})` replaces repeated `{name}` parameters with string values, including numbers.
Parameter names accept letters, digits, underscores, and dashes; unknown names retain their placeholders.
Only own catalog entries and parameters participate in lookup.

## Markup
```html
<button data-i18n="common.save" data-i18n-aria="common.save">Save</button>
<input data-i18n-placeholder="common.name" data-i18n-tooltip="common.name">
```

- `data-i18n` replaces `textContent`, including existing child markup.
- `data-i18n-aria` sets `aria-label`.
- `data-i18n-tooltip` sets both `data-tooltip` and `title`, matching meteo.
- `data-i18n-placeholder` sets `placeholder`.

Use a dedicated text span when controls contain icons or other children that must survive translation.
Translations always remain plain text; `data-i18n-html` has no special behavior.
Attribute translations have no interpolation parameters; use `t` for dynamic strings.

## Application lifecycle
`applyTranslations(root = document)` includes matching root elements and their descendants.
It accepts documents, elements, and document fragments, and leaves elements outside the root unchanged.
Call it after inserting content or changing catalogs; the module does not observe DOM mutations.
Shells own fetching, locale selection, persistence, fallback catalogs, events, and the document's language attribute.
Provide default-language markup until the shell applies translations.
No locales, storage keys, fetch paths, or language events are imposed by the package.
